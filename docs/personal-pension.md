# 个人养老金测算口径

本模块位于顶部独立的「个人养老金」Tab，仅测算今年一笔缴费。首次打开时从「单个工作」带入当前收入、奖金与扣除的年度合计，此后在本页独立编辑，切换 Tab 会保留输入。可以点击「重新带入当前工作」显式覆盖年度收入与扣除，年龄、缴费和收益假设不受影响。
本页可直接修改全年税前收入（已包含年终奖、额外激励）、其中的年终奖金额及计税方式、全年个人五险一金与专项附加扣除，并实时展示养老金扣除前的综合所得应纳税所得额。
不影响原有工资预扣汇总、月度明细或工作对比。40 岁、60 岁和 12,000 元为可修改的示例值。

## 年度个税

- 全年基本减除费用为 60,000 元，即使计薪不足 12 个月也不缩减。
- 直接使用本页填写的年度个人五险一金和专项附加扣除，不再乘以 12。首次带入时按当前工作的已录入计薪月份累计，不推断其他月份的收入和扣除。
- 年终奖并入综合所得时参与测算；单独计税时保持其税额不变。
- 个人养老金按实际缴费额在年度 12,000 元限额内扣除，限额不随计薪月份缩减。
- 预计节税 = 缴费前年税额 − 缴费后年税额，使用完整税率表计算，处理跨档和无应纳税所得的情形。
- 预计节税不是最终退税额，最终退补税还需要已预缴税额和其他所得等信息。

## 年化

税收优惠折算年化使用产品收益为 0 的现金流：现在缴费，抵税时收到税额差，在预计领取年龄一次性领取本金扣除 3% 税款后的金额。
次年退税按第 1 年收到，当年抵税按第 0 年收到；这是无具体日期的年度简化模型，不是精确到日期的 XIRR。

求使现金流净现值为零的 IRR，支持负年化。0 缴费或按分取整后当年抵税净投入为零时年化无定义，展示破折号。
产品收益假设按固定年化复利，领取时对账户本息按 3% 计税，重新求综合 IRR；
“税惠增加” = 综合 IRR − 产品预期年化，以百分点显示。退税不再投资。
收益率输入最多保留两位小数，展示与计算使用相同数值。
极小金额按分取整，长期收益和税率均为假设，不代表实际产品回报或未来税制。
预计领取年龄是测算条件，不校验法定退休年龄或实际领取资格。
