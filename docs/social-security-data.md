# 五险一金自动估算数据说明

更新日期：2026-07-23

## 计算口径

- 在职职工的缴费工资通常按本人上年度月平均工资申报；新入职人员通常按起薪当月工资申报。
- 缴费工资低于当地下限时按下限、高于上限时按上限，中间区间按实际申报工资。60% 与 300% 是常见的基数上下限规则，不是所有人都直接按社平工资 3 倍缴费。
- 自动模式估算个人承担的养老、医疗和失业保险，也估算公司承担的养老、医疗/生育、失业和工伤保险。工伤、生育保险个人通常不缴费。
- 公司工伤保险按当地公开行业档位中的最低比例计算；实际比例会随行业类别和浮动档位变化。
- 部分地区不同险种使用不同缴费基数，补充医疗、户籍、医保档次也可能改变金额。程序中的单一代表性范围用于工资预算，实际缴费应以工资条和主管部门最终核定结果为准。
- 个人与公司公积金月缴额分别按“缴存基数 × 对应比例”估算，缴存基数同样采用上年度月平均工资并受当地上下限约束。双方比例默认同步，取消「同步比例」后可分别选择；上海总比例可包含普通公积金与补充公积金。
- 公司总付出成本 = 税前工资 + 公司社保 + 公司公积金；不含招聘、商业保险、福利、残保金等其他成本。
