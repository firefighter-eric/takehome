# TakeHome

一个按中国居民个人工资薪金累计预扣法估算到手收入的网页计算器。

## 功能

- 输入税前月薪、上年度月平均工资和专项附加扣除
- 按工作城市自动估算个人与公司社保，个人扣款也可按工资条手动填写
- 个人、公司公积金比例分别可选，并自动计入各自金额
- 内置 20 个重点城市的社保、公积金比例、代表性基数上下限、执行期和来源链接
- 按 1–12 个计薪月份逐月计算累计预扣个税
- 按月薪倍数设置年终奖，可选择全年一次性奖金单独计税或并入综合所得
- 展示公司总付出成本、税前收入、税后收入和完整月度明细
- 响应式桌面与移动端界面
- 内置税率表、计算说明和输入校验

> 五险一金自动模式使用公开基数做工资预算。公司工伤保险按最低行业档估算，公司总成本不含招聘、福利、残保金等其他用工成本。部分城市不同险种的基数范围、补充医疗和参保档次可能不同；公积金比例也应按所在单位实际比例选择。

> 全年一次性奖金单独计税政策按财政部、税务总局公告 2023 年第 30 号实现，执行至 2027 年 12 月 31 日。单独计税优惠在一个纳税年度内通常只允许使用一次；年终奖不会在发放月重复扣一份社保公积金，但可能影响下一年度缴费基数。

五险一金数据的计算口径、城市清单和来源见 [docs/social-security-data.md](docs/social-security-data.md)。
